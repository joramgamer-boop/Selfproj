# Working Notes

## About the learner

- First sociology text ever. Build vocabulary from zero; never assume a term.
- Reading Mills for assigned coursework, so accuracy against the actual text
  matters more than a tidy summary. Quote page numbers.
- Wants all four outcomes: follow the argument, analyse real cases, explain it
  aloud, and write about it. That's broad — the ordering chosen is:
  **analyse cases first**, because Mills' own method is to reason from examples
  (unemployment, war, marriage, the metropolis), and because the
  trouble/issue distinction is the one tool that unlocks the other three.
